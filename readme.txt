Easily install and update GitHub-hosted themes and plugins, as well as all AJDWP products, with a single click.

== Description ==
**AJDWP GitHub Sync Plugin** makes managing GitHub-hosted WordPress themes and plugins a breeze. By providing the GitHub username, repository name, and branch, you can:
- Install themes and plugins directly from GitHub.
- Automatically keep them updated to their latest versions.
- Install and update all AJDWP plugins and themes with a single click.

This plugin simplifies the workflow for developers and users who prefer to host their projects on GitHub.

== Features ==
- Install themes and plugins from GitHub repositories.
- Automatically update GitHub-hosted themes and plugins.
- Seamlessly install and maintain AJDWP products.
- Lightweight and easy to use.

== Installation ==
1. Download the plugin ZIP file from [GitHub](https://github.com/arash12javadi/AJDWP-Github-Sync/archive/refs/heads/Plugin.zip).
2. Go to your WordPress dashboard, navigate to **Plugins > Add New**, and click **Upload Plugin**.
3. Select the downloaded ZIP file and click **Install Now**.
4. Activate the plugin through the "Plugins" menu in WordPress.

== Frequently Asked Questions ==

= How do I install a theme or plugin from GitHub? =
Navigate to the plugin's settings page and enter the GitHub username, repository name, and branch. Click "Install" to add it to your WordPress site.

= Will this plugin keep my GitHub-hosted themes and plugins updated? =
Yes! The plugin automatically checks for updates and ensures you have the latest versions installed.

= Does this work with private GitHub repositories? =
Currently, this plugin supports public repositories. Support for private repositories may be added in a future release.

= Can I use this plugin to install non-AJDWP themes and plugins? =
Absolutely! While it is optimized for AJDWP products, you can install and update any GitHub-hosted themes or plugins.
